# Hábitos alimentarios saludables

Presentación del informe de salud pública en la Urbanización Britania, Cartagena.

El archivo para proyectar o enviar es `presentacion/diapositivas.pdf`: 18 páginas en horizontal, una diapositiva por página.

También se puede abrir `presentacion/index.html` en el navegador. Las flechas, la barra espaciadora o el deslizamiento cambian de diapositiva.

El informe original está en `fuente/informe-salud-publica.pdf`. Las fotografías de las diapositivas son ilustraciones, no registros del trabajo de campo.
